# Antigravity Test App 🚀

A lightweight Android application configured to build **100% in the cloud** using **GitHub Actions**.

## 📁 Project Structure
* `app/src/main/java/com/example/testapp/MainActivity.kt`: Kotlin UI logic (interactive counter & dynamic states)
* `app/src/main/res/layout/activity_main.xml`: Modern Material UI dark layout
* `.github/workflows/android-build.yml`: Cloud compilation pipeline on GitHub Actions

## ☁️ How to Build & Download APK from Cloud
1. Push this folder to your GitHub account (`git init`, `git add .`, `git commit`, `git push`).
2. Open your repository on GitHub and click the **Actions** tab.
3. The build workflow will run on a high-speed 16GB RAM cloud runner.
4. Download the generated **`TestApp-Debug-APK`** and install it on your Android phone!
